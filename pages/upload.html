Choose a PDF and every page becomes an HD image on your Graphics page. Visitors cannot use this page. It only works with your private token.

Step 1. Connect to GitHub

Do this once. The token is like a private key that lets this page add files to your website.

  1. Open github.com/settings/personal-access-tokens/new.
  2. Name it Graphics upload and set an expiry (90 days is fine).
  3. Under Repository access, choose Only select repositories and pick Arthur-Creations.
  4. Under Permissions > Repository permissions, set Contents to Read and write. Nothing else is needed.
  5. Click Generate token, copy it, and paste it below.
